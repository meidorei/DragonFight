# DragonFight · 龙斗

可在本机运行的网页格斗游戏。原生 JavaScript + Canvas 2D，Node.js 内置工具，**零 npm 依赖**。支持电脑键盘与手机横屏触控。

## 开始游玩

1. 双击项目根目录的 `start.bat`。
2. 浏览器打开 `http://localhost:4173`。窗口保持打开；关闭窗口或 Ctrl+C 停止服务器。
3. 点击「进入对战」，选择模式、角色和控制方式，再点击「开始对战」。

已有 Node.js 22 或更新版本即可使用，无需 `npm install`。脚本不自动下载、安装软件，也不修改 PATH、注册表或防火墙。

手机：双击 `start-lan.bat`，电脑和手机连接同一 Wi-Fi，手机访问命令行打印的局域网地址并横屏。网络或防火墙阻止访问时需要检查当前网络配置；本项目不会自动修改。手机支持一个本地玩家，其余角色由 CPU 控制。

不要直接双击 `index.html`，浏览器的模块和素材加载需要 HTTP 服务。端口被占用时，在 PowerShell 使用 `$env:PORT='4174'; npm run dev`。`localhost` 和 `127.0.0.1`、不同端口各有独立的浏览器存档，请固定使用同一个地址。

## 键位

| 动作          | 1P        | 2P            |
| ----------- | --------- | ------------- |
| 移动          | A / D     | 左 / 右方向键      |
| 跳跃          | W 或空格     | 上方向键          |
| 持续防御        | S         | 下方向键          |
| 后撤闪避        | Q         | 小键盘 0         |
| 轻击 / 重击     | J / K     | 小键盘 1 / 2     |
| 技能一 / 二 / 三 | U / I / O | 小键盘 4 / 5 / 6 |
| 大招          | L         | 小键盘 3         |
| 暂停          | Esc       | Esc           |

设置页可修改键位；无小键盘可重新绑定 2P 按键。Windows 中文输入法可能拦截按键，游玩时切到英文输入。普通键盘的多键冲突取决于硬件，可通过改键避开。手机上推摇杆跳跃，技能按钮支持与摇杆同时按住。

## 模式与规则

- 单人对决：玩家对 CPU。简单 / 普通 / 困难影响反应延迟和决策。
- 同屏双人：两人在同一键盘上 1V1。
- 组队乱斗：2V2 同场，最多两名玩家，其他槽位为 CPU；可将两个玩家安排在同一队。关闭友军伤害，全队倒下判负。
- 训练场：不限时；静止、防御或战斗木桩，可控制自动恢复和无限能量。击倒后自动复活。
- 无尽闯关：1 对 1；每关前从随机三种强化中选一种，效果持续至本局结束并可叠加。
- 无尽激战：1 对 2，玩家基础生命和伤害翻倍，其他挑战规则相同。

普通比赛每回合 60 秒、三局两胜；超时按存活角色生命比例之和判胜。平局重开、不加分。挑战每关单回合，第二关起敌方生命每关 +5%、伤害每关 +3%；两个挑战分别保存最高通关纪录，没有中途续关。切换窗口或标签页会暂停。

所有模式都可以用擂台顶部的「判定框」按钮开启调试显示。青色是角色受击框，虚线表示无敌。红色是生效中的攻击框，黄色是飞行道具判定框。

命中、受击与防御获得能量，大招需要 100 能量。招式有前摇、生效、后摇；受击可能中断招式。防御只保护面向的一侧，有少量削血。闪避有短暂无敌和冷却，无法无限连用。

## 创建自己的角色

从这里开始：

- [角色制作规范](docs/角色制作规范.md)：素材尺寸、动作清单、配置与接入步骤。
- [AI 提示词](docs/AI提示词.md)：角色设定、分动作生成、交给编程 AI 的接入任务。
- [技能扩展接口](docs/技能扩展.md)：配置组合与自定义 JavaScript 模块。
- [架构与验证](docs/开发与验证.md)：命令、模块职责、检查方法与已知限制。
- `templates/character/`：可直接复制的完整样板角色，含透明 PNG。

最短流程：复制 `templates/character` 到 `characters/你的英文id` → 修改 `character.json` → 在 `characters/manifest.json` 添加路径 → `npm run check` → 刷新网页 → 训练场试打。高级技能再按文档注册一个独立插件。

「角色实验室」可预览动作、逐帧查看、显示锚点／判定框、加载 PNG 序列或精灵条，并导出精灵条与配置片段。导出文件需要手动放回角色目录；网页不会直接覆写源文件。AI 生成在你选用的工具里进行，游戏不内置模型调用或付费接口。

赤练、星遥和岩卫各有独立的头像和 17 套动作。奶龙沿用原有身体动画，头槌、护盾、泡泡弹和震地配有独立特效。新角色起步用的占位样板在 `templates/character/`。

## 开发命令

```text
npm run dev          本机开发预览
npm run lan          局域网预览
npm run check        配置、素材、技能引用和语法检查
npm test             Node 内置测试
npm run build        检查后生成 dist 静态目录
npm run preview      预览 dist
```

构建只是复制经过检查的静态资源，不安装工具、不调用 CDN。`dist/` 可以部署在普通 HTTP 静态服务器的根目录或子目录。源码修改后手动刷新；没有自动热重载。

## 数据与清理

角色和文档都在项目目录。设置和最高纪录保存在当前浏览器来源下的 `localStorage`，清理站点数据会清除它们；存储失败会显示提示，当前对局仍可继续。

停止 Node 进程后即可删除或移动整个项目目录；没有全局依赖、后台服务或系统配置残留。`dist/` 是可重新生成的构建输出。
