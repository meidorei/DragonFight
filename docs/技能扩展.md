# 技能配置与插件接口 v1

普通角色只改 JSON。复杂技能使用显式注册的本地 JavaScript 模块；这些模块与项目代码拥有相同信任等级，不是对不可信代码的沙箱。

## 内置效果

全部效果必须有 `type` 和 `at`；`at` 是相对于生效阶段起点的逻辑帧，范围为 `0 .. active-1`。

| type | 额外字段 | 行为 |
| --- | --- | --- |
| melee | range, height | 面朝方向矩形攻击，触发后持续至生效结束 |
| area | range, height，可选 visual | 以自身为中心、左右各 range 的范围攻击 |
| projectile | range, height, speed, duration | 发射一个弹道，range 是宽度，duration 是存活逻辑帧 |
| dash | speed | 从触发帧起到生效结束，沿出招时朝向突进 |
| shield | amount, duration | 添加吸收伤害的护盾，持续时间到期清零 |
| buff | multiplier, duration | 暂时改变伤害倍率，同类增益覆盖，不相乘 |
| plugin | plugin | 激活 registry 中对应的本地插件 |

伤害、击退、硬直取自所属招式，每个 melee/area 效果对每个目标最多命中一次；多个效果可产生多段伤害。弹道首次有效命中后消失，友军不能被命中。投射物宽高和攻击高度使用游戏世界单位。

为 `area` 添加 `"visual": "ground-impact"` 会在该效果开始时播放一次地面震波，仅影响画面。

`knockdown: true` 会令未防御目标倒地；普通攻击 `stun` 是硬直帧数。倒地 42 帧后起身 20 帧，起身无敌。防御需面朝攻击源、站在地上，承受 12% 伤害和较小击退。闪避前 12 帧无敌，总动作 22 帧，冷却 48 帧。

## 动画阶段

在招式上添加可选的 `phases`：

```json
"phases": {
  "startup": [0, 1],
  "active": [2, 3],
  "recovery": [4, 5]
}
```

数组值是对应动画中的零起始帧索引。该阶段的全部逻辑时间均匀映射到这些图片帧；例如 startup=12、两个图片帧，则每张显示 6 个逻辑帧。无映射时使用整段动画均匀播放。三个数组都必须非空，所有索引必须合法。

## 攻击特效

`vfx` 是招式可选的独立 PNG 特效数组，最多 16 项。将示例的 `vfx` 字段并入角色 `character.json` 的 `moves.skill1`，保留招式现有的 `effects`。这里使用总尺寸为 512×128 的横向精灵条。每帧 128×128，以 20 fps 播放约 0.2 秒。

```json
{
  "vfx": [
    {
      "at": 0,
      "src": "vfx/slash.png",
      "frameWidth": 128,
      "frameHeight": 128,
      "frames": 4,
      "fps": 20,
      "anchor": [24, 64],
      "offset": [55, 82],
      "size": 140
    }
  ]
}
```

| 字段 | 用法 |
| --- | --- |
| `at` | 从招式的生效阶段首帧起算，取 0 到 `active - 1` 的整数。 |
| `src` 或 `files` | 二选一。`src` 指向一行无间距的横向精灵条。`files` 按播放顺序列出独立 PNG，每张为单帧尺寸，数量等于 `frames`。使用相对角色目录的路径。 |
| `frameWidth`、`frameHeight` | 单帧宽高，均为 32～1024 的整数。 |
| `frames`、`fps` | 1～64 帧，帧数为整数。播放帧率为 1～60，每项按自己的 `fps` 播放一次。 |
| `anchor` | 图片像素坐标 `[x, y]`，由单帧左上角起算，两个坐标都在画布范围内。 |
| `offset` | 可选，脚底到特效锚点的 `[朝前, 向上]` 偏移，使用游戏世界单位，两个分量均为 −1200～1200。默认 `[0, 0]`。 |
| `size` | 可选，画面中的显示高度，范围 1～1024 游戏世界单位。保持原图宽高比，默认使用 `frameHeight`。 |

特效在 `at` 触发时取施放者当时的脚底位置，加上 `offset`。使用招式锁定的朝向，朝左时水平偏移与图片一起镜像。特效留在触发位置独立播完，挥空也会播放。伤害、碰撞与弹道仍由 `effects` 决定。需要既有地面震波时，可继续配置 `area` 的 `visual` 为 `ground-impact`。独立特效适合发力时出现在固定位置的刀光、火焰或爆炸，飞行中的弹道沿用 `projectile` 的渲染。

## SkillPlugin

参考 `src/plugins/second-wind.js`。示例技能在激活时回复 65 生命，并可在命中时显示一个装饰性光环。注册方式：

```js
import {moonPulse} from './moon-pulse.js';
export const skillPlugins = Object.freeze({
  'second-wind': secondWind,
  'moon-pulse': moonPulse,
});
```

配置引用：

```json
{"type":"plugin","at":0,"plugin":"moon-pulse"}
```

钩子全部同步调用，可按需要实现：

```js
export const moonPulse = {
  start(ctx, params) { ctx.heal(40); ctx.visual('heal'); },
  update(ctx, params) { /* 每个生效阶段逻辑帧调用 */ },
  hit(ctx, params) { /* 所属招式命中时调用，含格挡命中 */ },
  end(ctx, params) { /* 收招或被中断时调用 */ },
};
```

上下文是每次调用新建的冻结对象，不直接暴露可变世界：

| 字段／方法 | 说明 |
| --- | --- |
| frame | 当前回合逻辑帧 |
| health, maxHealth, energy | 施放者的当前快照 |
| targetId | 命中钩子的目标 ID，其余为 null |
| heal(n) | 回复 0～500 生命，不能超过最大生命 |
| addEnergy(n) | 调整能量，最终限制为 0～100 |
| visual('heal' / 'spark') | 添加短暂装饰效果 |

`params` 是该效果配置的浅冻结副本。不要修改 params 中的嵌套对象或共享角色配置。钩子报错会停用这次攻击中的该插件，并在页面提示；不会要求用户刷新才能继续游戏。

本版插件扩展能力有意限制在上述上下文方法内。传送、召唤独立战斗单位、控制对手、改变全局时间等能力尚无公开接口，不应通过导入引擎内部变量绕过。如将来确实需要，应先设计新的受控能力与测试。

## 无引擎修改的第四角色示例

复制完整模板，设置 `id: "fourth-hero"`。将 `moves.skill3.effects` 改为：

```json
[
  {"type":"plugin","at":0,"plugin":"second-wind"},
  {"type":"buff","at":0,"multiplier":1.2,"duration":180}
]
```

添加到清单并检查即可。现有测试会复制模板到临时目录，接入此类插件角色，在六种模式的世界中验证；测试结束后删除自己的临时目录。
